# AGENTS.md - Crypto Portfolio CLI

## Overview
Command-line tool for cryptocurrency portfolio tracking and analysis. Real-time prices, P&L tracking, and portfolio visualization.

## Tech Stack
- **Language:** Python 3
- **Dependencies:** See requirements.txt
- **Containerization:** Docker + docker-compose
- **License:** MIT

## Commands
```bash
pip install -r requirements.txt    # Install dependencies
python portfolio.py                # Run the portfolio tracker
docker-compose up                  # Run via Docker
```

## Project Structure
```
portfolio.py         # Main portfolio application
tests/               # Test suite
Dockerfile           # Container definition
docker-compose.yml   # Multi-container setup
```
